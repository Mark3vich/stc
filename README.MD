Клиент-серверное приложение на Qt 6: сервер хранит пользователей в SQLite, клиент на Widgets показывает список и позволяет добавлять новых.

Сборка.
Создайте папку build и перейдите в неё. Затем выполните команды: qmake ../stc.pro, после — make.
Для корректной работы сначала запустите сервер, затем клиент.
